# Justine Guia — Portfolio

A complete responsive portfolio inspired by the visual structure of the reference TikTok:
- dark/light theme
- minimalist developer aesthetic
- orange accent
- sticky navigation
- hero section
- about / experience / education
- featured projects
- GitHub-style activity
- tech stack
- certifications
- contact section
- resume download
- mobile navigation
- localStorage theme persistence

## Files
- index.html
- style.css
- script.js
- assets/Justine-Guia-Resume.pdf (placeholder location)

## Customize
1. Open `index.html`.
2. Replace the email, GitHub, Facebook, and project links.
3. Replace project descriptions with your final project information.
4. Replace the `JG` avatar with your photo if you want one.
5. Put your actual PDF resume at `assets/Justine-Guia-Resume.pdf`.
6. Open `index.html` in Chrome.

No framework or server is required.
